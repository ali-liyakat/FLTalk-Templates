# FLTalk Templates

This repository provides the official Federated Client and Federated Server templates for the FLTalk framework.

## Contents

```
Federated_Client/
Federated_Server/
```

## Getting Started

1. Download or clone this repository.
2. Configure the backend server URL.
3. Configure your local dataset and training parameters.
4. Start the federated server.
5. Start one or more federated clients.
6. Monitor the experiment through the FLTalk web interface.
